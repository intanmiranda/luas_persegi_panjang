B. JUDUL PROGRAM

program menghitung Luas Persegi Panjang

C. DESKRIPSI MASALAH

program ini dibuat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang dimasukkan oleh pengguna

D. TUJUAN PROGRAM

membantu pengguna menghitung luar persegi panjang secara cepat dan tepat

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
   - panjang persegi panjang (p)
   - lebar persegi panjang (l)

2. PROSES:
   - menghitung luas persegi panjang.
   - Eumus: luas = panjang = lebar.

3. OUTPUT:
   - Menampilkan hasil luas persegi panjang.

MULAI
  1. Deklarasi variabel Luas, panjang, lebar
  2. input nilai panjang persegi panjang 
  3. input nilai lebar persegi panjang
  4. hitung luas persegi panjang (L = p*l)
  5. tampilkan hasil luas persegi panjang
